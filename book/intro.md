# Six Thinking Hats + JupyterLite

This Jupyter Book accompanies the browser-based notebooks in the repository. It demonstrates a transparent workflow for using a custom Six-Thinking-Hats-GPT as a structured thinking partner, then converting the result into validated JSON and a reusable SVG mind map.

```{admonition} Attribution
The Six Thinking Hats method was developed by **Edward de Bono** and described in *Six Thinking Hats* (1985). The **Purple Hat — Orchestrator** in this project is an additional synthesis layer created for these notebooks; it is not part of de Bono's original six-hat method.
```

## Start here

- [Launch JupyterLite](https://jltobias.github.io/JupyterLite-Custom-GPT-Six-Thinking-Hats/lite/lab/index.html)
- [Open the repository](https://github.com/jltobias/JupyterLite-Custom-GPT-Six-Thinking-Hats)
- Read the workflow chapter, then run the notebooks in order.

The global-health example is inspired by the mind map supplied with this project and emphasizes responsible use: AI-generated perspective-taking can help structure questions, but evidence quality, data provenance, domain expertise, privacy, and uncertainty still require human judgment.
